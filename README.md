# RAJA GAMING STORE

This is a premium gaming storefront website inspired by modern storefront UI patterns.

Admin password: hamisi

Features included:
- responsive gaming landing page
- game cards and pricing
- payment section with number 0676 166 941
- admin login and add/delete game functionality
- localStorage-powered data persistence

To open locally:
1. Download or clone the repository
2. Extract the ZIP file if needed
3. Open `index.html` in your browser

To publish online with GitHub Pages:
1. Go to the repository settings
2. Open Pages
3. Choose Source: Deploy from a branch
4. Select branch: main
5. Select folder: /root
6. Save

Live URL after deploying:
https://doctarsaidi-dotcom.github.io/raja-gaming-store/
